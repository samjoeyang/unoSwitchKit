## 彩虹圈修复 (v0.3.1, 16:55)

用户反馈：每次点开面板鼠标转彩虹圈半天。
根因：Tauri 同步命令默认跑在主线程——打开面板要同步执行 10+ 个外部进程（defaults read ×10、Finder AppleScript 数废纸篓、sw_vers），加上 5s 一次的 sidecar 轮询(最长 8s)全在主线程。
修复：commands.rs 全部耗时命令改 async fn（24 个），State<'_, AppState> + Result 返回（异步命令用借用 State 的硬性要求）；is_prevent_sleep 改收 &AppState；quit_app 保持 sync（瞬时）。前端 invoke 接口零改动。
教训：Tauri 2 命令凡是 spawn 子进程/网络 IO 的必须 async，否则面板 UI 会冻住。

## 菜单栏收纳点击无效果 → 方案重构（v0.3.2, commit df2f29c）

- 用户反馈收纳点击没效果。实测定案：macOS 12 上 AX 写状态项位置**一律 -25200(kAXErrorFailure)**——其它进程/本进程/setFrameOrigin/orderFrontRegardless 全部无效（读正常写全拒）。Hidden Bar 官方架构文档确认「macOS 无公开 API 移动其它 App 菜单栏图标」。
- 重构为 Hidden Bar v1.10 同款「分隔条撑开」：守护自建「箭头+分隔条」状态项，收起=分隔条长度撑到 max(500,min(最宽屏×2,10000)) 挤走左侧图标。点亮=⌘拖到箭头右侧，autosaveName 持久化。自动摆放(autoplace)无公开 API 可行，代码保留待新系统。
- 途中修复：守护 try! NWListener 端口占用即崩（改 40×0.5s 重试）；NSStatusItem 必须在 NSApplication.shared 之后创建（CGSConnectionByID 断言崩溃）；状态项按钮点击需 NSApplication.run()（原 RunLoop.main.run() 不处理事件）；守护日志落 ~/Library/Logs/switchkit-daemon.log。
- ⚠️ 教训：**应用/守护二进制重编译后 TCC 辅助功能授权会失效**（负责进程 cdhash 变化），需用户在系统设置重新勾选；核心收纳功能不依赖该授权（仅图标列表枚举需要）。
- 测试技巧：WorkBuddy 沙箱内 ps/launchctl 被禁，spawn 的后台进程会随会话回收；真实验收要 launchctl kickstart -k gui/501/com.switchkit.app 走 LaunchAgent，再 nc/python 直连 :9876 发 JSON 行协议。
