
## 首轮实机反馈修复 (v0.1.1, 14:41)

用户实机跑通 tauri dev 后反馈 3 个问题，已修复并通过双端编译：

1. **托盘图标彩色扎眼** → 新增 `src-tauri/icons/tray-icon.png`（36×36 单色开关 glyph，18pt @2x——tray-icon crate 源码硬编码 `icon_height=18.0`），`tray.rs` 用 `include_bytes!` 内嵌 + `icon_as_template(true)` 模板化，自动适配菜单栏深浅色。
   - 坑：Tauri 2.12.5 的 `TrayIconBuilder` 是 newtype 包装，但暴露 `icon_as_template(bool)`；`Image::from_bytes` 需 `image-png` feature（已启用）。registry 源码上 grep 会静默失灵，用 python 读文件才查得到。
2. **面板底部裁切无法滚动** → 窗口固定 `inner_size(320, 540)`，`index.css` 给 `#root` 加 `overflow-y: auto` + 细滚动条。根因是原 CSS `height:100% + body overflow:hidden` 且窗口无显式尺寸。
3. **废纸篓计数错(显示0)** → `trash_count`/`empty_trash` 改为 Finder AppleScript 权威来源（`count of items in trash` / `empty trash`），失败回退直读 `~/.Trash`。沙箱内 `~/.Trash` 是隔离空视图，无法本地复现计数问题，Finder 方案保证与用户在 Finder 看到的一致。首次调用会弹一次"控制 Finder"TCC 授权。
4. 面板 `visibilitychange` 时自动刷新状态，修过期计数。

版本号同步 0.1.1（package.json / tauri.conf.json / App.tsx 角标 / CHANGELOG）。

## 勾选开机自启出现两个托盘图标 (14:54)

根因：`store.rs` 的 LaunchAgent plist 带 `RunAtLoad`，`launchctl load` 立即拉起第二个实例 → 两个图标。
修复：接入 `tauri-plugin-single-instance v2.5.5`（main.rs builder 第一个注册 `.plugin()`，回调唤起已有面板），第二实例（launchd 拉起或手动双开）启动即退出；`set_launch_at_login` load 前先 unload 幂等化。cargo check 通过。

## 菜单栏图标收纳功能 (15:10, Bartender/Ice 类 MVP)

用户需求：把菜单栏其他 App 图标收进面板，默认隐藏、点亮才显示。
实现（swiftc 多文件坑：顶层语句文件必须叫 main.swift，daemon.swift 已改名）：
- `swift/menubar.swift`：AX API 枚举各进程 AXExtrasMenuBar，AXPosition 移出屏幕左缘=收纳，移回记录原位=恢复；MenuBarManager 每 3s 巡检，新图标自动收纳；visible 判定 x>-100。
- 协议 `menubar:list` / `menubar:apply`(ownPid+managed+visibleIds+positions)；bridge/daemon 接线；daemon 启动 requestTrustOnce 弹辅助功能授权。
- Rust：sidecar_call 超时参数化复用；menubar_state(枚举+合并白名单+推送策略+持久化位置)、menubar_set_visible、menubar_set_managed；main.rs spawn_sidecar(exe 旁或 binaries/<triple>，9876 已监听则跳过，std::mem::forget 独立生命周期)。
- Settings 增 menubar_managed(默认 true)/menubar_visible/menubar_positions。
- 前端 MenuBarSection.tsx（点亮/收纳切换+管理总开关+授权提示），App.tsx 接入。
- Swift 值类型坑：AXValueType 是 .cgPoint/.cgSize（非 cgPointPoint）；NWConnection.start 要显式 queue；bridge 缺 import Network。
- 产物：src-tauri/binaries/switchkit-daemon-x86_64-apple-darwin（已 gitignore，构建指南有 swiftc 命令）。
- 限制：Control Center 系统项（Wi-Fi/电池）可能拒动；守护被杀则隐藏项停在屏外，重启 App 由持久化位置恢复。

## 扩展开关与即时动作 (v0.2.0, 16:00)

仿 One Switch 面板补齐功能，用户裁剪决定：台前调度按系统版本条件显示(<13 隐藏)、夜览不做(依赖第三方)、锁定键盘不做(风险)。

新增开关：hide_dock(defaults autohide+killall Dock)、show_hidden_files(AppleShowAllFiles+killall Finder)、screen_clean(System Events visible false/true，按 unix id 跳过自身，状态存 AppState.screen_cleaned)、stage_manager(com.apple.WindowManager GloballyEnabled，13+ 才有)。
即时动作：lock_screen(CGSession -suspend，回退 pmset displaysleepnow)、clear_clipboard(: | pbcopy)、start_screensaver(open -a ScreenSaverEngine)、close_all_apps(System Events 逐个 quit，osascript -t 15 限超时防存盘框卡 IPC)。

坑：get_toggle_states 里 State<AppState> 传入 is_prevent_sleep 是 move，之后不能再借用 → 先读 screen_cleaned 再移入。ToggleStates 加 stage_manager_available 供前端条件渲染。
验证：cargo check 通过、npm run build 通过。版本 0.2.0。
