## 为 build.yml 接入 OTA 在线更新（连接到最新发布的 Release）
- 原状：updater 插件已注册但 `tauri.conf.json` 的 `plugins.updater.endpoints` 为 `[]`，构建工作流未设 `SWITCHKIT_UPDATE_ENDPOINTS`，更新功能默认禁用、且无 manifest/签名包。
- 改动 `build.yml`：仅当 `secrets.TAURI_SIGNING_PRIVATE_KEY` 存在时启用 OTA——注入 `bundle.createUpdaterArtifacts:true` + endpoints(`https://github.com/<repo>/releases/latest/download/latest.json`) 到 tauri.conf.json；用私钥签出 `SwitchKit.app.tar.gz`+`.sig`；生成 `latest.json`（平台键 darwin-x86_64/aarch64，signature 取 .sig 内容）；用 `softprops/action-gh-release@v2` 发布 tag `v<version>` 的 Release（含三 zip + 两份 .tar.gz/.sig + latest.json）。未配私钥则整条 OTA 跳过，退化为纯三架构构建。
- 改动 `scripts/build-release.sh`：新增 `SKIP_CONF_RESTORE=1`，CI 连跑多架构构建时跳过还原 tauri.conf.json，由工作流统一 `git checkout` 还原。
- 关键依赖（用户需在仓库 Secrets 配置）：`TAURI_SIGNING_PRIVATE_KEY`（Ed25519 私钥内容，来自 ~/.switchkit-updater-secret.key）。pubkey 已在 tauri.conf.json。
- 注意：运行该工作流会**公开发布 GitHub Release**（远程写操作），属推送级动作，需用户明确同意后再跑；我只写文件不运行。
- OTA 安装顺畅还需 Developer ID 签名+公证（已有 APPLE_* secret 接线）。
