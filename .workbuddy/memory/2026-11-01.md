## 修复：原生守护点不亮 + 图标更新 + 本地 universal 构建并邮件交付

### 根因（重要，可复用）
- 现象：面板「原生守护」状态点始终不亮，`nc -z localhost 9876` 长期 CLOSED，`NWListener` 的 `stateUpdateHandler` 从不触发；但 Python 裸 socket 能 bind 9876、最小 `NWListener` 测试在 9877 能跑。
- 真因：**本机 Tailscale 网络扩展**（`io.tailscale.ipn.macsys.network-extension`）在 Network 框架层拦截 `bind()`，导致 `NWListener` 永远不就绪；裸 BSD socket 不受拦。用户机器若跑 Tailscale 也会中招。
- 修复：守护进程网络层从 `NWListener/NWConnection`（Network 框架）改为**裸 BSD socket**（`socket/bind/listen/accept` + GCD read source 驱动连接处理），`dispatchMain()` 常驻。swiftc 去掉 `-framework Network`。已实测 9876 LISTEN + `ping`→`{"ok":true}`。
