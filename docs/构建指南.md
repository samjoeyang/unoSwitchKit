# 构建与运行指南（SwitchKit）

> 适用对象：从零搭建 / CI / 实体机联调。
> 本仓库已在 macOS 12.7.6 + Rust 1.99 下通过 `cargo check`（后端）与 `npm run build`（前端）验证。

## 1. 前置依赖

| 依赖 | 版本 | 安装 |
|---|---|---|
| Node.js | ≥ 18 | `brew install node` |
| Rust (stable) | ≥ 1.77 | `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` |
| Xcode Command Line Tools | — | `xcode-select --install` |
| blueutil（仅蓝牙功能需） | latest | `brew install blueutil` |
| Tauri CLI | v2 | 随 `npm install` 进入 `devDependencies`，用 `npm run tauri` 调用 |

### Rust 双架构 target（universal 包用）

```bash
source "$HOME/.cargo/env"
rustup target add aarch64-apple-darwin x86_64-apple-darwin
```

### Swift 守护进程（sidecar）编译

菜单栏图标收纳、蓝牙设备（IOBluetooth）由 Swift 守护承载，`tauri dev/build` 不会自动编译它，需先手动构建（Rust 启动时按 `src-tauri/binaries/switchkit-daemon-<arch>-apple-darwin` 自动拉起）：

```bash
cd src-tauri/swift
swiftc -O -framework AppKit -framework ApplicationServices -framework Network -framework IOBluetooth \
  main.swift bridge.swift menubar.swift bluetooth.swift \
  -o ../binaries/switchkit-daemon-$(uname -m)-apple-darwin
```

> 排查守护问题时看 `~/Library/Logs/switchkit-daemon.log`（收纳动作与 AX 错误码都写在这里）。

> 发布 universal 包时分别用 `-target x86_64-apple-darwin` 与 `-target arm64-apple-darwin` 各编译一次，再 `lipo -create` 合并。

## 2. 本地开发

```bash
npm install
npm run tauri dev      # 启动前端(dev server) + 编译/运行 Rust，支持热更新
```

> `tauri dev` 会先 `npm run dev`（Vite @ :1420）再启动 Rust 主进程。
> 首次编译 Tauri 依赖较多（数分钟），请耐心等待。

## 3. 生产构建

```bash
./scripts/build-release.sh                # 当前架构
./scripts/build-release.sh --universal    # Apple Silicon + Intel 通用包
```

脚本自动完成：Swift 守护编译（含 ad-hoc 签名）→ 签名身份检测 → `tauri build`（守护进程经 `externalBin` 打进 `Contents/MacOS/switchkit-daemon`）→ 产物签名收尾与校验。

不用脚本时的手动等价流程：

```bash
npm run tauri build                         # 当前架构
npm run tauri build -- --target universal-apple-darwin   # Apple Silicon + Intel 通用包
```

产物位于 `src-tauri/target/(debug|release)/` 或 `src-tauri/target/universal-apple-darwin/release/`。

## 3.1 分发签名策略

| 场景 | 签名 | 用户首次打开体验 |
|---|---|---|
| 内测（本脚本默认，无证书） | ad-hoc（`codesign -s -`） | 弹「未验证开发者」，右键 → 打开；macOS 13+ 需 系统设置 → 隐私与安全性 → 仍要打开 |
| 公开分发 | Developer ID Application + 公证 | 双击直接打开 |

ad-hoc 包注意：
- 守护进程**已随包签名**，不会被系统静默拦截；功能完整，仅入口多一步信任操作。
- 想跳过弹窗可让用户执行 `xattr -cr /Applications/SwitchKit.app`（清隔离属性）。
- 公开分发前必须完成公证，见 §6。

## 4. 分发前准备（NFR-2 / 设计文档 §8）

- **Apple 公证（notarize）**：公开分发必需，未公证的包会被 Gatekeeper 拦截，详见 §6。
- **自动更新**：生产引入 `tauri-plugin-updater`（基于 Sparkle），本 MVP 未接入。
- **App Store**：暂不走 App Store（沙盒会限制系统命令），官网/直链分发。

## 5. 权限说明（运行时）

| 操作 | 是否需 root | 通道 |
|---|---|---|
| 深色模式 / 隐藏桌面 / 阻止睡眠 / 清空废纸篓 | 否 | 直接 shell |
| 释放内存（`purge`） | 是 | `osascript … with administrator privileges` 弹系统密码框 |
| 刷新 DNS | 是 | 同上 |
| 清理用户缓存 | 否（用户级） | 仅白名单目录 |
| 蓝牙开关 | 否 | Swift sidecar 调 `blueutil` |
| 菜单栏图标收纳 | 否 | Swift sidecar 走 AX API，需「辅助功能」授权 |

> 凭据不落盘、不进日志、不硬编码。生产环境应替换为 `SMJobBless` privileged helper（设计文档 §4.5）。

## 6. 公证分发（公开分发时必做）

### 6.1 前提

| 项目 | 说明 |
|---|---|
| Apple Developer Program | ¥688/年 |
| Developer ID Application 证书 | developer.apple.com 手动创建（CSR 流程），只有账户持有人可建 |
| App 专用密码 | appleid.apple.com → 登录和安全 → App 专用密码 |

### 6.2 存储公证凭证（一次性）

```bash
xcrun notarytool store-credentials "switchkit-notary" \
  --apple-id "你的AppleID" --team-id "TEAMID"
# 按提示输入 App 专用密码，凭证进钥匙串，之后不落明文
```

### 6.3 Tauri 配置与构建

`tauri.conf.json` 无需加公证字段，环境变量齐全即自动公证：

```bash
export APPLE_SIGNING_IDENTITY="Developer ID Application: 你的名字 (TEAMID)"
export APPLE_CERTIFICATE_PASSWORD=""        # 证书导入钥匙串时如设过密码才需要
export APPLE_ID="你的AppleID"
export APPLE_PASSWORD="App专用密码"
export APPLE_TEAM_ID="TEAMID"
./scripts/build-release.sh
```

Tauri 自动完成：hardened runtime 签名（含 `externalBin` 守护进程）→ `notarytool submit --wait` → `stapler staple`。

### 6.4 验证

```bash
APP=src-tauri/target/*/release/bundle/macos/SwitchKit.app
spctl -a -vv "$APP"                # 期望: accepted source=Notarized Developer ID
xcrun stapler validate "$APP"
codesign -dv "$APP/Contents/MacOS/switchkit-daemon"   # 守护进程必须已签名，否则公证被拒
```

### 6.5 手动公证（不依赖 Tauri 自动流程）

```bash
ditto -c -k --keepCompressed "$APP" SwitchKit.zip
xcrun notarytool submit SwitchKit.zip --keychain-profile "switchkit-notary" --wait
xcrun stapler staple "$APP"
```

## 7. 常见问题

- **面板不显示 / 黑屏**：确认 `tauri.conf.json` 中 `bundle.macOS.activationPolicy = "accessory"`，且窗口 `transparent: true` 时背景为透明（毛玻璃由 CSS 实现，非系统 vibrancy）。
- **`cargo check` 报 frontendDist 缺失**：先 `npm run build` 生成 `dist/`，或保留占位 `dist/index.html`。
- **蓝牙开关无效**：确认已 `brew install blueutil`，且 Swift sidecar 已随包启动（面板底部「原生守护」状态点应点亮）。
- **菜单栏图标列表为空 / 无法收纳**：需在 系统设置 → 隐私与安全性 → 辅助功能 中勾选 `switchkit-daemon`（首次启动守护会弹引导）；Control Center 的部分系统项（Wi-Fi/电池等）可能拒绝移动，属系统限制。
- **最低系统版本**：开发机为 macOS 12，构建用 `minimumSystemVersion = 10.13`；发布前请上调至 **Ventura 13** 以匹配 PRD。
