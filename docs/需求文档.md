# 需求文档（PRD）—— Mac 菜单栏快捷开关 + 系统资源释放工具

> 项目名：SwitchKit ｜ 工程目录：`unoSwitchKit`
> 技术栈：Tauri 2.0（Rust）+ React + TypeScript + Swift sidecar
> 文档版本：v0.1 / 2026-10-30

---

## 1. 项目概述

### 1.1 背景
- **One Switch**：macOS 菜单栏常驻工具，提供一键切换系统状态（深色模式、隐藏桌面、阻止睡眠、清空废纸篓等）。
- **CleanMyMac X**：系统优化工具，提供"释放内存""刷新 DNS""清理缓存"等资源释放能力。

### 1.2 目标
构建一个 **macOS 专属、常驻菜单栏、体积极小（安装包 < 15MB、常驻内存 < 50MB）** 的工具，让用户用最少点击完成系统状态切换与资源释放。

### 1.3 范围
- **平台**：仅 macOS，最低 Ventura 13，目标适配 macOS 26（Tahoe）菜单栏。
- **形态**：菜单栏图标（`NSStatusItem` 等价物），无 Dock 图标、无 App Switcher 条目（`activationPolicy: accessory`）。
- **非目标**：跨平台（Win/Linux）、文件管理、杀毒、完整的 CleanMyMac 全套清理（首版只做高频资源释放项）。

---

## 2. 目标用户
- Mac 重度用户、开发者、设计师。
- 痛点：频繁切换系统状态（演示前隐藏桌面、看视频阻止睡眠），或系统变卡时想快速"释放内存/清缓存"而不打开臃肿工具。

---

## 3. 功能需求

### FR-1 菜单栏面板
- 点击菜单栏图标，在图标正下方弹出无边框面板。
- 点击面板外部（含切换到其他 App）自动收起。
- 多显示器下面板定位到图标所在屏幕。
- 面板内分区：**快捷开关区** + **资源释放区** + **设置入口**。

### FR-2 系统快捷开关
每个开关需展示"当前状态"（开/关 高亮），点击即切换。

| 编号 | 开关 | 实现方式 | 是否需要 root | 优先级 |
|---|---|---|---|---|
| FR-2.1 | 深色模式 | `osascript` 调 System Events 或 `defaults` | 否 | P0 |
| FR-2.2 | 隐藏桌面图标 | `defaults write com.apple.finder CreateDesktop -bool false; killall Finder` | 否 | P0 |
| FR-2.3 | 阻止睡眠 | `caffeinate -dimsu -w <pid>` 启停 | 否 | P0 |
| FR-2.4 | 清空废纸篓 | `osascript` / 删除 `~/.Trash/*` | 否 | P0 |
| FR-2.5 | 启动屏保 | `open -a ScreenSaverEngine` | 否 | P1 |
| FR-2.6 | WiFi 开关 | `networksetup -setairportpower en0 on/off` | 否 | P1 |
| FR-2.7 | 蓝牙开关 | `blueutil`（第三方 CLI）/ IOBluetooth 框架 | 否 | P1 |
| FR-2.8 | 夜间护眼（Night Shift） | 私有 API / `nightshift` CLI | 否 | P2 |
| FR-2.9 | AirDrop / Handoff | 私有 API（需原生） | 否 | P2 |

### FR-3 系统资源释放
| 编号 | 功能 | 实现方式 | 是否需要 root | 优先级 |
|---|---|---|---|---|
| FR-3.1 | 释放内存（RAM） | `purge` | **是** | P0 |
| FR-3.2 | 刷新 DNS 缓存 | `dscacheutil -flushcache; killall -HUP mDNSResponder` | **是** | P0 |
| FR-3.3 | 清理用户缓存 | 删除 `~/Library/Caches` 下白名单目录 | 否（用户级） | P0 |
| FR-3.4 | 进程/端口释放 | `kill` / `pkill` / `launchctl` | 部分需 root | P1 |
| FR-3.5 | 清理 Xcode 派生数据 | 删除 `~/Library/Developer/Xcode/DerivedData` | 否 | P2 |
| FR-3.6 | 释放后展示效果 | 释放前后内存占用对比（读 `vm_stat` / `sysctl`） | 否 | P1 |

> 缓存清理必须走**白名单路径**机制（见 NFR-3），禁止递归清空整个 Library。

### FR-4 开机自启
- 提供开关，注册/移除 `~/Library/LaunchAgents/<bundle-id>.plist`（RunAtLoad）。

### FR-5 全局快捷键（可选 P1）
- 可自定义快捷键唤起面板 / 触发某开关（Tauri 全局快捷键插件或 Swift 监听）。

### FR-6 设置与持久化
- 记录：面板开关顺序、自启开关、缓存清理白名单、上次的资源释放结果。
- 用 `tauri-plugin-store` 持久化到规范路径。

### FR-7 状态实时反映
- 面板打开时即读取各开关当前真实状态（如用 `defaults read` 判断深色模式），而非本地记忆，避免与系统设置不同步。

## 4. 非功能需求

### NFR-1 性能
- 常驻内存 **< 50MB**（Tauri 实测 30–40MB，显著优于 Electron 150–400MB）。
- 冷启动 **< 0.5s**。面板弹出无可见延迟。

### NFR-2 体积
- 安装包 **< 15MB**（Tauri 使用系统 WebView，不打包 Chromium）。

### NFR-3 安全（关键）
- **不调用私有 AppKit API**（规避 macOS Tahoe 26 上 Electron 类全局卡顿前科）。
- 缓存/文件删除仅允许**白名单目录**，删除前二次确认，可配置"仅统计不删除"预览模式。
- 所有文件操作限制在用户主目录内（`~`），禁止越权路径。
- 不收集、不上传任何用户数据。

### NFR-4 权限
- 需要 root 的操作（FR-3.1/3.2）走**特权提升通道**：
  - MVP：弹 macOS 密码框（`osascript` `with administrator privileges`）。
  - 生产：打包 **privileged helper（`SMJobBless`）**，常驻最小权限守护进程执行单一 root 命令。
- **绝不**在代码或配置中硬编码任何凭据。

### NFR-5 兼容性
- 最低 macOS 13 Ventura；适配 macOS 26 菜单栏（确认 `activationPolicy: accessory` 与托盘 API 在目标版本可用）。
- Apple Silicon 与 Intel 双架构（universal binary）。

### NFR-6 可维护性
- 前端（React）与后端（Rust 命令）职责清晰，系统命令集中在 Rust 命令层，便于审计与替换。

---

## 5. 验收标准
1. 菜单栏图标显示，面板弹出/收起符合 FR-1。
2. FR-2 的 P0 开关（深色模式/隐藏桌面/阻止睡眠/清空废纸篓）点击可切换且状态正确回显。
3. FR-3 的 P0（释放内存/刷新 DNS/清缓存）均可执行；root 操作能正确弹出授权。
4. 常驻内存 < 50MB，安装包 < 15MB。
5. 缓存清理仅命中白名单、有预览确认，无越权删除。
6. 开机自启开关生效。

---

## 6. 里程碑（建议）
- **M1**：Tauri 2.0 菜单栏骨架（托盘 + 无边框面板 + accessory 模式 + 自启）。
- **M2**：FR-2 P0 开关全部打通（纯 shell 的 4 项）。
- **M3**：FR-3 P0 资源释放 + 权限提升通道。
- **M4**：Swift sidecar（蓝牙/监听）+ FR-2 P1 + 设置持久化 + 打磨。
