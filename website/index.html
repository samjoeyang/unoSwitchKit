把 Mac 的常用开关
收进菜单栏

SwitchKit 是一款 macOS 专属的菜单栏快捷开关 + 系统资源释放工具。一键深色模式、阻止睡眠、释放内存、管理蓝牙、查看多平台模型余额——常驻菜单栏，体积极小。

Features

菜单栏里的全能控制中心

快捷开关

深色模式、隐藏桌面图标、阻止睡眠、清空废纸篓、隐藏 Dock、显示隐藏文件、屏幕清洁、台前调度（macOS 13+）。

即时动作

锁定屏幕、清空剪贴板、启动屏幕保护、一键关闭所有应用（优雅退出，自动跳过自身与 Finder）。

蓝牙设备

列出已配对设备，一键连接 / 断开。走系统 IOBluetooth 框架，无第三方依赖。

资源释放

释放内存（purge）、刷新 DNS、清理用户缓存（白名单 + 预览 + 二次确认），释放前后智能对比。

模型余额

DeepSeek、Kimi、智谱 GLM、阶跃星辰、Novita、OpenRouter、302.AI、AiHubMix 及中转站，多账号混排、60 秒自动刷新。

菜单栏收纳

像 Bartender / Ice 一样收纳其它 App 的菜单栏图标：默认收起，点亮的才显示，自动记住布局。

开机自启

一键注册 LaunchAgent，自带单实例保护，不会出现双托盘图标。

在线更新

基于 tauri-plugin-updater，面板「检查更新」一键下载安装并重启，无需手动来回。

安全优先

缓存删除仅限白名单且在主目录内；root 操作凭据不落盘、不进日志；默认不联网、不上报。

Install

安装方式

三步完成。分发包为 ad-hoc 签名、未公证，按下方提示首次放行即可。

📋 系统要求

✓
macOS 10.14 及以上（台前调度开关仅 macOS 13+ 显示，其余功能不受影响）
✓
Apple Silicon 与 Intel 均支持，分发包为 universal 通用二进制
✓
蓝牙整机开关需额外 brew install blueutil（可选）

🔐 首次运行需授予的权限

权限用途
自动化 (Finder)清空废纸篓、关闭所有应用
完全磁盘访问清理 Safari 等受保护缓存（需重启 App 生效）
蓝牙列出 / 连接蓝牙设备
管理员密码释放内存、刷新 DNS（凭据不落盘）

🚀 安装步骤

  1. 下载。前往 官网下载页，按芯片选择对应版本（Apple 芯片选 arm64、Intel 选 x86_64、不确定选 universal），下载压缩包。
  2. 解压并拖入应用程序。在本地双击解压得到 SwitchKit.app，把它拖进 /Applications（「应用程序」文件夹）。不要在压缩包内直接双击运行。
  3. 首次启动。打开「应用程序」文件夹，直接点 SwitchKit 图标打开（无需在 Finder 里右键）。macOS 会弹出安全警告，按下方 4 步放行即可，只需一次。

启动后没有 Dock 图标，点菜单栏上的 SwitchKit 图标即可展开面板。若下方步骤仍提示「已损坏，无法打开」，在终端执行下面命令移除隔离属性后重试：

xattr -dr com.apple.quarantine /Applications/SwitchKit.app

💻 命令行方式（可选）

熟悉终端的用户也可全程用命令行完成下载、解压与首次放行：

# 1. 下载（以 universal 为例，按需替换版本号与架构）
curl -LO https://github.com/samjoeyang/unoSwitchKit/releases/download/v0.4.1/SwitchKit-0.4.1-universal.zip

# 2. 解压（分卷先合并：zip -s 0 X.zip --out full.zip && unzip full.zip）
unzip SwitchKit-0.4.1-universal.zip -d /tmp/sk
mv /tmp/sk/SwitchKit.app /Applications/

# 3. 移除隔离属性并打开（绕过 Gatekeeper 拦截）
xattr -dr com.apple.quarantine /Applications/SwitchKit.app
open /Applications/SwitchKit.app

🗑 卸载

launchctl unload ~/Library/LaunchAgents/com.switchkit.app.plist 2>/dev/null
rm -f ~/Library/LaunchAgents/com.switchkit.app.plist
rm -rf /Applications/SwitchKit.app
rm -rf ~/Library/Application\ Support/com.switchkit.app
